# cus-tree · 윈저성의 성탄 트리

- 상태: 점검 통과
- 크기: 큰 카드(장면 4개: 1800년, 왕비의 주목 나무 → 1848년, 신문 속 트리(한가운데 · 찾아보기) → 바다 건너 미국으로(1850년 12월) → 1850년 성탄 전야(인용 장면))
