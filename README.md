# 처음 만나는 기독교 문화

카드 477장으로 펼쳐 보는 기독교 문화 입문서예요.

- `site/` 폴더가 홈페이지 전체예요.
- `tools/` 폴더는 홈페이지를 만드는 도구예요(홈페이지에는 나오지 않아요).
- 사진과 그림은 저작권이 끝났거나 자유 이용이 허락된 것, 그리고 주인에게 이 책에서 쓰도록 따로 허락받은 사진만 쓰고, 카드마다 출처를 적었어요. ‘허락을 받아 씀’이라고 적힌 사진은 다른 곳에서 쓸 수 없어요.
- 글은 출처를 밝히면 비영리로 자유롭게 나누고 고쳐 써도 돼요(CC BY-NC-SA 4.0 · https://creativecommons.org/licenses/by-nc-sa/4.0/deed.ko). 돈을 받는 곳에서 쓰려면 따로 허락을 받아야 해요.
