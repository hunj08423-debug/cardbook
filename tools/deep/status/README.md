# 카드 상태 파일

카드마다 `tools/deep/status/<카드id>.md` 하나. 만드는 창이 쓰고, 상태가 바뀔 때마다 고쳐요. 본부와 다음 창은 이 파일만 보고 이어 갈 수 있어야 해요.

```markdown
# <카드id> · <카드 제목>
- 묶음: <번호> · 장: <장 이름>
- 상태: 조사 중 | 그림 허락 기다림 | 만드는 중 | 방식 기다림(<모듈>) | 점검 통과 | 사용자 검토 중 | 고침 반영 | 끝 | 작은 카드
- 크기: 큰 카드 | 한 장면 카드 | 작은 카드
- 두 질문: 1) 그 자리에 있고 싶은 한 순간 — … / 2) 손으로 하는 한 가지 — …(이야기 속 무엇에서)
- 중심 방식: … · 도우미: …
- 끝맺는 꼴: … · 이야기 속 무엇에서: …
- 본부 소식: <번호>번까지 따름
- 기준서: 1판(보탬 10) · 틀: deep3-4 · 키트: 3판(2026-11-18)
- 그림·소리: <몇 개> · 출처 기록 deep_src/<카드id>/_sources.json · 원본도 사용자 폴더 deep_src에 보냄
- 인물 사진 요청: 없음 | 보냄(<날짜>) · <파일 이름> | 받음(<날짜>) | 안 씀(<까닭>)
- 그림 받기 부탁: 없음 | 보냄(<날짜>) · 묶음<번호>.bat | 받음(<날짜>)
- 화질: 품질 85(키트 2판 보탬) | 원본 없음 · 옛 화질
- 기계 점검: 문제 0 · 살펴볼 것 <n>(남긴 까닭)
- 사실 대조:
  | 문장(앞부분) | 출처 | 결과 |
  |---|---|---|
  | 1833년 11월, … | Das Rauhe Haus PDF | 맞음 |
- 사용자 의견과 고친 것:
  - <날짜> “…” → …
- 본부에 제안: (틀·키트·규칙 후보. 없으면 ‘없음’)
- 작은 카드일 때 ‘더 깊이’ 글: (한두 칸, 출처 포함)
- 마지막 갱신: <날짜 시각>
```
