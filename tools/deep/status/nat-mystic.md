# nat-mystic · 신비로운 성탄
- 묶음: 13 · 장: 1장 기다림과 성탄
- 상태: 점검 통과(사용자 검토 기다림)
- 크기: 큰 카드(장면 5개: 1500년 어지러운 피렌체 → 그림 꼭대기의 글 → 하늘이 열리고(찾아보기, 한가운데) → 정의와 평화가 입을 맞추다(고르기) → 로마에서 런던까지)
- 두 질문: 1) 그 자리에 있고 싶은 한 순간 — 하늘의 둥근 춤이 땅까지 내려와 천사와 사람이 끌어안고, 악마가 바위 틈으로 숨어드는 순간(보티첼리가 꼭대기 글에 ‘이 그림처럼’ 보게 되리라고 적은 장면) / 2) 손으로 하는 한 가지 — 보티첼리가 그림에 적고 그려 넣은 것(그리스어 글, 리본, 흔들리는 왕관, 올리브 관, 숨는 악마)을 하나씩 찾아 읽기(이야기 속 물건: 화가가 직접 써넣은 글과 그림 속 표시)
- 중심 방식: 찾아보기(look · 새 방식 제안, 사용자 확인 전) · 도우미: 고르기(“나라면 어느 천사와 함께하고 싶나요?”)
- 4·5단계: 4 = 그림 속 일곱 곳 모두 찾아 읽기(look) · 5 = 함께할 천사 고르기(choose) 또는 아이와 함께 끝까지 보기(kid)
- 이웃 카드: 앞 mad-chartres(상태 파일 없음) · 뒤 nat-latour 비추기 → 겹치지 않음. mad-chartres를 만드는 창은 찾아보기를 피해야 해요.
