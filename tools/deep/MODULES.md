# 손 방식 설명서 (키트 2판 · 2026-11-18 · 보탬: 놓아 보기·그때와 지금 문구를 카드 자료로 바꾸기)

카드마다 **중심 방식은 하나**, 도우미는 한두 개까지예요(기준서). 방식은 이야기에 실제로 있던 물건·행동에서 골라요.
중심 방식이 들어간 장면이 그 카드의 ‘그 자리에 있고 싶은 한 순간’, 곧 한가운데 장면이에요.

## 한눈에 보기

| 방식(기준서 이름) | 모듈 | 상태 | 어울리는 이야기 | 4단계 기록(id) |
|---|---|---|---|---|
| 날짜 따라가기 | `wreath` | 있음 · 대림절 화환 전용 | 대림절처럼 날마다 하나씩 여는 기다림 | `wr3`·`wr7`·`wr24` |
| 소리 | `voices` | 있음 · 소리 줄기를 만들어야 해요 | 노래, 전례 | `vo3`·`vo6` |
| 놓아 보기 | `place` | 있음 · 무대 그림(SVG)을 새로 그려야 해요 | 사물로 이루어진 장면 | `plOrder`·`home` |
| 비추기 | `reveal` | 있음 · 자료만 적으면 돼요 | 어둠, 발견, 숨은 글씨 | `reveal` |
| 그때와 지금 | `slider` | 있음 · 자료만 적으면 돼요 | 장소가 남아 있는 이야기 | `slider` |
| 지도 위 길 | `route` | 있음 · 자료만 적으면 돼요 | 여행, 피란, 순례 | `route` |
| 찾아보기 | `look` | 있음 · 사용자 확인(2026-11-18): **장 전체에서 네 장에 한 장쯤까지** | 그림·이콘·유리창·건물 속 작은 것들 | `look` |
| 도우미: 고르기 | `choose` | 있음 · 자료만 적으면 돼요 | ‘우리라면 어디에/무엇을’처럼 이야기 속 행동을 내 자리로 | `choose` |

틀에 없는 방식 이름을 쓰면 빌드가 그 장면을 그림으로만 보여 주고 알려 줘요(‘방식 기다림’). 새 방식이 필요하면 status ‘본부에 제안’에 적어요.

**고루 쓰기(기준서 1판 보탬 9)**: 묶음 안에서 같은 중심 방식은 두 장까지, 같은 도우미(`duo`·`thennow`·`choose`)도 두 장까지. 찾아보기는 장 전체에서 네 장에 한 장쯤까지. 묶음 점검(`check.py <묶음 카드들>`) 맨 끝에 방식이 어떻게 섞였는지 나와요.

지금도 바로 쓸 수 있는 도우미(장면 종류):
- `'kind': 'thennow'` — 그때/지금 두 그림을 탭으로 바꿔 보기(`'then'`, `'now'`, `'thenT'`, `'nowT'`). 한 카드에 하나만 써요(둘째부터는 탭이 움직이지 않아요). 손잡이로 겹쳐 보려면 중심 방식 `slider`를 써요.
- `'kind': 'duo'` — 두 그림 나란히(`'imgs': ['a', 'b']`, `'caps'`). 예: 화환 카드 마지막 장면.
- `'kind': 'quote'` — 큰 인용 장면(`'quote': {'t', 'from', 'u'}`).
- 장면의 `'snds'` — 옛 녹음 듣기 버튼(`{'u': '파일.mp3', 't': '이름', 'd': '설명', 'ev': '기록id'}`), `ev`를 5단계 길로 쓸 수 있어요. 예: 고요한 밤 마지막 장면.

## 어디에 무엇을 적나(모든 방식 공통)

```python
'scenes': [ ...,
  {'id': 'night', 'label': '그 밤', 'kind': 'mod', 'mod': '<모듈>', 'night': True,   # night: 이야기에 밤이 있을 때만
   'text': ['…'], 'quote': {...}, 'text2': ['…'], 'kid': '…', 'kidq': '…'}, ... ],
'mods': {'<모듈>': { ...방식마다 다른 자료... }},
'goals': {'s4': {..., 'ways': [{'id': '<4단계 기록 id>', 't': '…'}]},
          's5': {..., 'ways': [{'id': '<이야기 안의 행동 id>', 't': '…'}, {'id': 'kid', ...}]}},
'film': [ ...,
  {'type': 'mod', 'mod': '<모듈>', 'ch': 3, 'lines': [{'t': '자막', 'act': '<움직임>', 'wait': 1500}, ...], 'kid': [...]}, ... ],
```
- 영화 자막 한 줄의 `'act'`가 화면 속 방식을 움직여요(방식마다 다름). `'wait'`은 그 줄을 더 오래 보여 줄 밀리초.
- `'q': True, 'from': '…'`은 인용 자막, `'ask': True`는 아이와 함께 볼 때 멈춰서 묻는 자막이에요.
- 5단계 길에는 항상 `kid`(아이와 함께 끝까지 보기)를 하나 넣어요.

## 있는 방식

### 날짜 따라가기 — `wreath` (예시: `cards/lig-wreath.py`)
대림절 첫 주일부터 12월 24일까지의 초를 둥근 화환에 그려요. 대림절 중이면 오늘 초를 켜고, 대림절 전이면 찾아온 날마다 다음 초가 밝아져요. 날짜는 계산으로 구해요.
- 자료: `'mods': {'wreath': {'looks': {'then': '…', 'now': '…'}, 'eve': '…'}}` + `'modhtml': {'wreath': '…'}`(예시 카드에서 그대로 옮겨 글만 고쳐요).
- 기록: `wr3`(서로 다른 날 세 번), `wr7`(일곱 번), `wr24`(12월 24일).
- 영화 `act`: `'run'`(초가 차례로 켜짐). 영화 칸에 `'n'`(초 수), `'look'`, `'d0'`, `'dsub'`.
- 대림절이 아닌 다른 절기(사순절·부활 50일 등)는 아직 없어요. 필요하면 status ‘본부에 제안’에 적어요.

### 소리 — `voices` (예시: `cards/sil-score.py`)
여러 소리 줄기(악기·목소리)를 하나씩 켜고 끄며 듣고, 노랫말 줄이 소리에 맞춰 밝아져요.
- 소리 만들기: 퍼블릭 도메인 가락을 악보(MIDI)로 적고 `kit/song_example_silent.py`처럼 `kit/fsynth.py`로 줄기마다 따로 만들어요(같은 길이, mp3 80k, 한 개 1MB 안쪽). 만든 소리는 ‘이 안내서가 만든 소리’라고 밝혀요.
- 자료: `'sounds'`(파일과 출처), `'mods': {'voices': {'dur', 'lines'(줄마다 at·end), 'verses'(절마다 cap·원어·우리말), 'parts'(줄기마다 u·이름), 'firstHint', 'startHint'}}`, `'modhtml'`.
- 기록: `vo3`(모든 줄기를 켜고 끝까지), `vo6`(모든 절 펼쳐 읽기). 영화는 `'sync': True`와 줄마다 `'at'`(초)로 소리에 맞춰요.
- 손이 많이 가요. 노래가 이야기의 한가운데일 때만 써요.

### 놓아 보기 — `place` (예시: `cards/cus-greccio.py`)
어두운 무대에 물건을 하나씩 놓으면 장면이 완성되고, 마지막에 밝아져요(`body.daylight`).
- 무대 그림: `kit/place_stage.py`의 `stage_svg()`처럼 SVG로 그려요. 놓을 물건마다 `data-o="<id>"` 무리가 있어야 하고, 불빛은 `.lt` 무리예요. 실루엣은 `kit/art/`(소·나귀·양)를 쓸 수 있어요.
- 자료: `'mods': {'place': {'items'(id·t·la·say), 'order', 'intro', 'climax', 'home'(고르기 낱말들), 'svg'}}`, `'modhtml'`.
- 불빛을 켜는 물건은 id를 `'lights'`로 해요. 그러면 무대 그림의 `.lt` 무리가 차례로 켜져요(다른 물건은 `data-o="<id>"` 무리).
- 그레초 말고 다른 카드에서 글을 바꾸는 칸(키트 2판 보탬 · 모두 적지 않아도 돼요. 적지 않으면 그레초 문구 그대로):
  ```python
  'home': None,                 # ‘우리 집이라면’ 고르기를 안 쓸 때(None 또는 []). 다 놓은 뒤 그 칸이 나오지 않아요. 따로 고르기를 하려면 도우미 `choose`
  'homeLabel': '우리 집 슈톨렌 자리',   # 고른 뒤 보이는 말과 4·5단계 상태 글 앞머리(기본 ‘우리 집 구유 자리’)
  'homeWait': '다 만든 뒤 고를 수 있어요',   # 고르기 전 상태 글(기본 ‘그레초의 밤을 다 놓아 본 뒤 고를 수 있어요’)
  'wrongOrder': '박물관 기록에 남은 차례는 이래요: {order}',   # 차례가 틀렸을 때 문장. {order} 자리에 'order'가 들어가요(이렇게 끝에 두면 받침 걱정이 없어요)
  'orderDone': '기록 차례대로 다 쌓았어요',   # 4단계 상태 글(기본 ‘기록 차례대로 다 놓았어요’)
  'daylight': False,            # 끝에 화면 전체가 낮처럼 밝아지지 않게(밤 이야기가 아닐 때). 무대만 밝아져요
  ```
  `'home'`을 안 쓰면 `'modhtml'`의 `.pl-home` 칸은 그대로 두어도 나오지 않아요(테마 CSS로 숨기지 않아도 돼요).
- 기록: `plOrder`(기록 차례대로 다 놓기), `home`(‘우리 집이라면’ 고르기). 영화 `act`: 물건 id, `'day'`.
- 손이 많이 가요. 물건의 차례가 기록에 있을 때 가장 좋아요.

## 자료만 적으면 되는 방식 (키트 2판)

`'img'`·`'then'`·`'now'`는 `images`의 키예요(`'card'` = 사이트 앞면 그림). `x`·`y`는 그림 왼쪽 위에서 잰 **퍼센트**예요(왼쪽 끝 0, 오른쪽 끝 100). 그림을 `Read`로 열어 보고 어림해요(5~95 사이로). `modhtml`은 적지 않아요(틀이 만들어요). 그림 출처 줄은 틀이 그림 아래에 붙여요.
빌드한 뒤에는 check.py 스크린샷(`*_mod.png`)에서 점·표시가 제자리에 있는지 꼭 눈으로 확인해요.

### 비추기 — `reveal`
어둠 속 그림을 손가락(마우스)으로 문지르면 빛이 닿은 곳만 드러나요. 숨은 표시(`marks`)에 빛이 닿으면 이름이 떠요.
```python
'mods': {'reveal': {
  'img': 'manuscript', 'light': 'candle',          # candle(촛불) · torch(횃불) · lamp(등불)
  'intro': '손가락이나 마우스로 문질러 비춰 보세요.',
  'marks': [{'x': 32, 'y': 41, 't': '지운 글자 자국', 'p': '한두 문장(출처 있는 사실)'}],   # 0~5곳
  'after': '다 비췄을 때 나오는 한두 문장',
}},
```
- 기록: `reveal` = 표시를 다 찾음(표시가 없으면 그림 대부분을 비춤). ‘모두 밝히기’ 버튼도 있어요(누구나 끝까지 볼 수 있게).
- 영화 `act`: `'light'`(빛이 그림 위를 천천히 지나감), `'mark:1'`(1번 표시를 비춤), `'all'`(모두 밝힘).

### 그때와 지금 — `slider`
같은 자리의 옛 그림과 오늘 사진을 겹쳐 놓고, 가운데 손잡이를 밀어 비교해요.
```python
'mods': {'slider': {
  'intro': '가운데 손잡이를 밀어 그때와 지금을 겹쳐 보세요.',
  'pairs': [{'then': 'gottheil', 'now': 'rh2016', 'thenT': '1850년 무렵', 'nowT': '2016년',
             'p': '무엇이 남고 무엇이 바뀌었는지 한두 문장'}],   # 1~3쌍
}},
```
- 두 그림은 되도록 같은 방향에서 본 것으로. 다르면 솔직하게 `p`에 적어요.
- 장소가 아닌 것을 겹쳐 볼 때(옛 달력·새 달력처럼) 글을 바꾸는 칸(키트 2판 보탬 · 적지 않으면 기본 문구):
  `'hint': '손잡이를 양쪽 끝까지 밀어 두 달력을 겹쳐 보세요'`(다 보기 전 상태 글), `'doneText': '두 달력을 끝까지 겹쳐 봤어요'`(다 본 뒤), `'pairsLabel': '끝까지 겹쳐 본 달력'`(쌍이 둘 이상일 때 ‘○ / ○’ 앞말).
- 기록: `slider` = 모든 쌍을 양쪽 끝까지 밀어 봄.
- 영화 `act`: `'then'`(그때로), `'now'`(지금으로 천천히), `'half'`(반반), `'pair:2'`(둘째 쌍으로). 영화는 첫 쌍에서 시작해요(그때가 다 보이는 상태).

### 지도 위 길 — `route`
지도 위에서 ‘다음 곳으로’를 누를 때마다 길이 한 구간씩 그려지고, 그곳의 이야기가 열려요.
```python
'mods': {'route': {
  'img': 'map1',                                   # 지도 그림 키. 알맞은 지도가 없으면 'paper'(종이 바탕 위에 점과 길만)
  'intro': '‘다음 곳으로’를 눌러 길을 따라가 보세요.',
  'stops': [{'x': 22, 'y': 64, 't': '베네치아', 'd': '1844년 4월', 'p': '한두 문장'},
            {'x': 71, 'y': 38, 't': '…', 'd': '…', 'p': '…'}],   # 2~8곳, 가는 차례대로
  'end': '도착했을 때 한 줄',
}},
```
- 기록: `route` = 마지막 곳까지 따라감.
- 영화 `act`: `'go'`(다음 구간), `'stop:3'`(3번 곳까지), `'all'`(길 전체).

### 찾아보기 — `look` (사용자 확인 · 장 전체에서 네 장에 한 장쯤까지)
큰 그림 속 작은 것들을 하나씩 눌러 찾고 읽어요. 이콘·명화·유리창·건물·사본처럼 ‘그림 자체가 이야기’인 카드에 어울려요.
```python
'mods': {'look': {
  'img': 'card',
  'intro': '그림 속 작은 것들을 하나씩 눌러 보세요.',
  'spots': [{'x': 62, 'y': 78, 't': '구유 속 아기', 'p': '한두 문장', 'kid': '아이용 한 줄'}],   # 3~7곳
  'done': '다 찾았을 때 한 줄',
}},
```
- 기록: `look` = 모든 곳을 찾아 읽음. ‘가까이 보기’ 단추로 고른 곳을 크게 볼 수 있어요(`'zoom': 2` 배율, 기본 2).
- 영화 `act`: `'spot:2'`(2번 곳으로 다가감), `'all'`(전체).

### 도우미: 고르기 — `choose`
이야기 속 행동을 ‘우리라면?’으로 이어 보는 작은 고르기예요. 정답은 없어요. 아무 장면에나 `'choose': True`를 적으면 그 장면 끝에 나와요.
```python
'mods': {'choose': {
  'q': '우리 집이라면, 작은 구유를 어디에 놓을까요?',
  'opts': [{'t': '현관', 'r': '고른 뒤 보여 줄 한 줄'}, {'t': '창가', 'r': '…'}],   # 2~5개
}},
```
- 기록: `choose`(고른 낱말이 함께 남아요). 5단계 길로 써요.
- **묶음 안에서 두 장까지만**, 붙은 두 카드가 연달아 쓰지 않게(기준서 1판 보탬 8). ‘우리라면?’만 되풀이하지 말고 이야기 속 사람의 자리에서 고르는 물음도 써요(고른 뒤 `r`에 기록에 남은 일 한 줄). 다른 마무리는 GUIDE.md 2장을 봐요.
- ‘마음에 남은 장면 고르기’처럼 이야기 밖의 과제가 되지 않게, 이야기 속 행동과 이어지는 물음만 써요.
