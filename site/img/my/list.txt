# ================================================================
#  직접 넣은 사진 목록
# ================================================================
#
#  사진을 카드에 넣는 방법
#  1) 사진 파일을 이 폴더(site/img/my)에 넣어요.
#     파일 이름은 그 카드의 아이디로 바꿔 주세요.  예) sai-lisieux.jpg
#  2) 아래에서 그 카드 줄을 찾아 맨 앞의 "# "(샵과 빈칸)을 지워요.
#  3) | 뒤에 사진 출처를 적어요. 칸의 차례는 이래요.
#       파일 이름 | 사진 설명과 출처 | 사진이 있던 주소
#     예) keep-tischendorf.jpg | 1860~70년대의 티셴도르프 · 사진: 후고 크바스 사진관(베를린) · 퍼블릭 도메인 · 위키미디어 공용 | https://commons.wikimedia.org/wiki/File:...
#  4) 이 파일을 저장하고 GitHub Desktop에서 Commit, Push를 누르면 1분쯤 뒤 사이트에 나와요.
#
#  알아 두면 좋은 점
#  - "#"으로 시작하는 줄은 사이트가 읽지 않아요.
#  - 파일 이름은 영어 소문자 그대로 써 주세요. jpg, png, webp 모두 돼요.
#    사진이 png라면 줄 맨 앞의 파일 이름도 .png로 고쳐 주세요.
#  - 윈도우 탐색기의 "보기"에서 "파일 확장명"을 켜 두면
#    sai-lisieux.jpg.jpg처럼 이름이 겹치는 실수를 막을 수 있어요.
#  - 사진 파일이 폴더에 없으면 그 줄은 건너뛰고 원래 그림을 보여 줘요.
#  - 얼굴이 잘려 보이면 네 번째 칸에 가로·세로 위치를 적어요.
#    예) ... | 주소 | 50 20   (0~100, 숫자가 작을수록 왼쪽·위쪽이 보여요. 비워 두면 50 30)
#  - 여기 없는 카드에도 넣을 수 있어요. 카드를 열었을 때
#    주소창 끝의 "#c-" 뒤가 카드 아이디예요.
#  - 줄 앞에 "#"을 다시 붙이면 원래 그림으로 돌아가요.
#
#  라이선스가 Public domain(퍼블릭 도메인), CC BY, CC BY-SA인 사진을 골라 주세요.
#  요즘 인물 사진과 한국 인물 사진은 기념관이나 기념사업회의 허락을 먼저 받아 주세요.
#
